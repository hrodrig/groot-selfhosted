Helm repository · GROOT

This site hosts the Helm chart index for scheduled in-cluster GROOT collection (CronJob + RBAC + optional PVC). Published from groot-selfhosted. Helm clients fetch index.yaml from this base URL — a browser is optional.

Add the repo and install

helm repo add groot https://hrodrig.github.io/groot-selfhosted
helm repo update
helm search repo groot -l
helm upgrade --install groot groot/groot \
  --namespace groot --create-namespace \
  --set image.tag=1.0.3

Use helm show values groot/groot to customize; pin chart version with --version from helm search.
